Как считается

Отчёты 03 и сводки 05–08 читают RPC базы, не ячейки книги. Исключения — вес с «Товар+Вес», ЗаказыЛК и регион поставки: их по-прежнему даёт файл 02 с листов этой книги.

Вес / к-во продаж

RPC report_finance_daily. Дата rr_dt. Только Продажа / Возврат. Продажа +, возврат −. Вес = шт × «Товар+Вес» (хук 02, иначе 0).

Реклама

Расход = Σ (клики × CPC), не колонка spend API. ДРР = расход / нетто выручка. Стык артикула через products.vendor_code.

Заказы FBW

С 02 — лист ЗаказыЛК (C дата, D артикул, G к-во, I имя, K вес). Без 02 — report_fbo_orders_daily.

Заказы FBS

report_fbs_orders_daily, день = created_at МСК. Дни на листе подряд от A1 до A2.

Поставка_new

A1–A2 заказы, A3–A4 в пути, A5 горизонт. Остатки — последний снимок. В пути — FBW не «Принято» (код 5). К поставке = max(0, горизонт×среднее − остаток − в пути). Печать: Поставка_2 склад в B5, Поставка_new блок в B4 («Склад WB» / «Склад продавца»). Файл «склад_ГГГГММДД_ЧЧ-ММ-СС.xlsx», не temp.

info

Продажи нетто. Реклама клики×CPC. К перечислению — все строки дня. Daily: к пред. и к среднему 7д. Weekly всегда пн–вс. История переписывается утром, не выбором даты. Пример: Продажа 82 − Возврат 1 = 81 на info.

sku / stock

Те же формулы в разрезе nm_id. Остатки: спрос 7 полных дней, снимок остатка, покрытие в днях. Меню «stock».

Книга: окно «Дней» — старше удаляем, середину не трогаем, из базы вчера+сегодня и дыры. Лимит ~6 мин, продолжит через минуту.

Новый клиент → база

1
Токен WB: статистика, финансы, реклама, FBS, поставки FBW. Не в git.
2
slug латиницей уникальный, history_from — с какой даты история.
insert into public.sellers (name, slug, history_from)
values ('ООО Асме', 'acme', '2026-03-01');
select vault.create_secret('WB_ТОКЕН', 'wb_token_acme');
-- npx supabase secrets set WB_TOKEN_ACME=WB_ТОКЕН
3
История: POST /functions/v1/enqueue-history с {"slug":"acme"} и service_role. Тик сам разгребёт.
4
Контроль sync_jobs / load_runs. Daily подхватит is_active с 05:00. Выключить: is_active = false.

Новый клиент → книга

1
Пустой Spreadsheet, не копия боевой книги (чужие Товар+Вес).
2
Скопировать 01, 03, 05–08 и html. Не копировать 02 и 04, пока не заказан оверлей.
3
Ключ базы = anon JWT (eyJ…), не service_role.
4
Создать настройки → кабинет = slug → Загрузить всё → Ежедневно 05:05.
5
Листы отчётов с A1/A2, функции 03. Сверка supabase/sql/sheet_check.sql.
Вес и регион новому клиенту — отдельный файл 02, не общая часть. Меню: stock, без «Сводная». Telegram: клавиатура внизу (Цифры, Обновить всё, Один блок, Отменить), команд в Menu нет, /start ставит кнопки. Цифры / утро: buildInfoText — блоки info daily, HTML жирные заголовки, Δ только к вчера. Daily done → sync-tick одно сообщение: эти цифры + «✅ База 11/11». 09:00 notify-digest только если ошибки. Обновить всё / Один блок → enqueue + request_bot_load; когда джобы done — «✅ База обновила… Загрузите лист в Google». Книга из бота сама не заливается. sku утром не пересчитывается.
